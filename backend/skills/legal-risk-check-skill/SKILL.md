# LegalRiskCheckSkill · 法律风险与合规审核

## 功能描述
识别文书或案件材料中的合规风险、条款风险、要素缺失、空白项、风险等级和修改建议。合并了法律合规、通用合规、风险评分和条款风险识别能力。

## 输入参数
- `document_content`: 待审核的文书/材料正文
- `context`: 案件上下文（可选，用于补充判断）
- `check_type`: 检查类型（合同审核/证据风险/合规审查）

## 执行步骤
### 1. 要素完整性检查
检查是否存在空白项、待填写、未约定等要素缺失。
**使用MCP工具:** `deepseek_server`（可选，复杂判断场景）

### 2. 条款风险识别
识别高风险条款（违约金过重、管辖不明、付款无逾期后果等）。

### 3. 合规风险识别
检查是否符合法律合规要求，识别违规表述和风险点。

### 4. 风险评分与分级
按风险严重程度打分，输出高/中/低风险等级和修改建议。

## 输出结果
```json
{
  "score": 0.82,
  "level": "中",
  "risks": [{"severity": "high", "title": "…", "suggestion": "…", "legal_basis": "…"}]
}
```

## 使用的MCP工具
- `deepseek_server`: 复杂风险判断（可选，规则为主）

## AI服务
- DeepSeek：复杂条款风险判断（可选增强）

- 平均耗时: 200ms - 500ms（规则）；含 LLM 时 2s - 5s
- 主要瓶颈: LLM 调用（增强场景）
