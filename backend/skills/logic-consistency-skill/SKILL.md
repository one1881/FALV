# LogicConsistencySkill · 逻辑一致性检查

## 功能描述
检查案情、诉求、证据和金额口径之间的逻辑冲突，识别事实矛盾、请求冲突、金额口径不一致、条款闭环不足和证据逻辑问题。

## 输入参数
- `case_summary`: 案情摘要
- `claims`: 诉讼请求列表
- `evidence_items`: 证据列表（可选）
- `document_content`: 文书正文（可选）

## 执行步骤
### 1. 事实矛盾检查
对比案情描述与请求/证据，识别前后矛盾的事实表述。

### 2. 请求冲突检查
检查诉讼请求之间是否相互冲突或重复。

### 3. 金额口径检查
核对案情、请求、证据中的金额是否一致。

### 4. 条款闭环检查
检查合同条款是否形成完整闭环（权利-义务-违约-救济）。

### 5. 输出不一致清单
返回所有发现的不一致点和修改建议。

## 输出结果
```json
{
  "status": "warning",
  "issues": [{"type": "金额口径不一致", "detail": "…", "suggestion": "…"}]
}
```
